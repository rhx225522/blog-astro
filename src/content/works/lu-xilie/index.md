## 这是一件什么作品

一套以「鹿」为主题的插画。鹿在传统语境里是「禄」，是祥瑞，也是最好认的一个侧影——所以我用同一只鹿的身体，去试不同的工艺语言。

## 五条并行的视觉路线

| 风格 | 处理方式 |
|---|---|
| 敦煌 / 珐琅彩 | 蓝绿身体、卷草纹、粉色花点缀 |
| 鎏金浮雕 | 金色鹿身、雕花边框、暗底打光 |
| 波斯细密画 | 红鹿与鸢尾、郁金香、柏树并置 |
| 玉雕 / 铜雕 | 深绿石质、螺旋纹、厚重阴影 |
| 青花 / 剪纸 | 深蓝底、白色线描、留白取胜 |

## 为什么它重要

这套图后来成了整个站点的视觉底色：配色、纹样与留白都从这里借。也就是说，它既是一件作品，也是这个博客的「设计规范」。

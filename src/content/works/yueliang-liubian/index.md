## 这是一件什么作品

一个单页交互网站，主题是《月亮与六便士》。页面不是把书评贴上去，而是把书拆成可以逐张看的东西：人物介绍卡、巴黎的书页、画室的引文、烧掉的画、遗言金句、海上明月。

## 页面的六个单元

1. 人物介绍卡
2. 书页卡 · 巴黎
3. 引文卡 · 画室
4. 燃烧的画
5. 金句卡 · 遗言
6. 海上明月

配三段旁白音频（开场、我必须画画、结尾提问），另有一支合成的成片。看、读、听三种入口并存。

## 技术做法

HTML + CSS + JavaScript 三件套，不依赖框架。图片做了抠图处理（金月亮、绅士背影），保证卡片叠在背景上不出现白边。
